# ملاحظات الواجهة — ما تم إصلاحه وما يحتاج API

مرجع: `docs/ملاحظات قسم (تحليلات الجهات ).docx` و `docs/ملاحظات داشبورد (1).docx`

## تم إصلاحه في الواجهة (Frontend)

| المشكلة | الإصلاح |
|---------|---------|
| فلتر المحافظات فارغ في تحليلات الجهات | كان يستخدم `g.label` / `g.value` بدل `g.name` / `g.id` — تم التصحيح |
| فلتر الوقت لا يدعم «كل الأوقات» | إضافة خيار `days=0` وعدم إرسال `days` للـ API |
| فلتر «تجميع حسب» لا يُرسل | إصلاح `mergeAnalyticsFilters` ليمرّر `granularity` من الفلاتر العامة |
| أسماء #1 #2 في الدائري | تحسين `pickSliceLabel` و`formatDistributionChart` و`pieLabel` |
| محور الزمن / امتداد الرسم | `scrollable` للخطي/الأعمدة عند أكثر من 6 نقاط |
| أرقام المحافظات في التقارير | `governoratesService` + `governorateId` في فلاتر التقارير |
| ملخص المحافظة: `governorateId is required` | فلتر محافظة إلزامي عند جهة «المحافظة» |
| أسماء المحافظات في جداول التحليلات | تحويل أعمدة `governorateId` إلى أسماء عند توفر القائمة |

## يحتاج تعديل من الـ API (Backend)

### تحليلات الجهات — عام

| # | المطلوب | ملاحظة |
|---|---------|--------|
| 1 | `GET /api/gov/analytics/reports/{id}?days=` اختياري | عند عدم إرسال `days` = كل الأوقات |
| 2 | احترام `granularity=day\|week\|month` | على تقارير الخط الزمني |
| 3 | احترام `governorateId` | على كل التقارير المعلّمة في `supportedFilters` |
| 4 | شرائح الدونات: `nameAr` / `nameEn` أو `label` | بدل قيم رقمية فقط |
| 5 | عمود المساحة (هكتار) | `Farms.AreaHectares` في البيانات و`areaHectares` في الاستجابة |
| 6 | فلتر نوع المنتج (خضار/فواكه) | `productCategoryId` أو `productType` في الفلاتر |
| 7 | فلاتر من/إلى محافظة | `fromGovernorateId`, `toGovernorateId` للرحلات والكميات المنقولة |
| 8 | فلتر خط النقل | `transportLineId` أو `routeId` |
| 9 | `topN` للمنتجات (مثلاً 70) | تقارير «أعلى/أقل إنتاجاً» |
| 10 | ترجمة أنواع الشكاوى/المستخدمين | `nameAr` في الاستجابة وليس مفاتيح إنجليزية فقط |
| 11 | تقارير بدون بيانات | الشكاوى، المنتجات قليلة التوفر، متوسط زمن النقل، إلخ — التحقق من الاستعلامات |
| 12 | `governorate-summary` لجهة المحافظة | قبول `governorateId` إلزامي من الفلتر (الواجهة ترسله الآن) |
| 13 | خريطة الإنتاج | `visualizationType: map` مع `points[]` أو ربط بـ `/api/gov/maps/products` |

### تقارير النظام (Reports)

| التقرير | الحالة المتوقعة من API |
|---------|------------------------|
| تقرير المبيعات | إصلاح endpoint — كان يعطي error |
| نشاط المستخدمين / تسجيلات | إصلاح endpoint |
| مخزون المنتج | إصلاح endpoint |
| المناقصات الممنوحة / التوفير | إصلاح endpoint |
| إيرادات المزادات | إرجاع بيانات للرسم |
| الإيرادات (أسبوع/سنة) | إصلاح تجميع `timeGroup` |
| طرق الدفع / المعاملات / أرباح وخسائر | إرجاع بيانات |
| تقارير المخزون والأداء والخسائر | إرجاع بيانات أو إزالة من القائمة |
| تحليل السوق | إرجاع بيانات |
| المبيعات حسب الموقع | محور زمن يتغير مع `startDate`/`endDate`/`timeGroup`؛ محافظات بأسماء وليس أرقاماً في الصفوف |

### لوحة الحكومة

| # | المطلوب |
|---|---------|
| 1 | التحقق من منطق KPI (إيرادات، حجم، أسعار) — أرقام غير منطقية قد تكون من بيانات تجريبية |
| 2 | `days` اختياري في `/api/gov/dashboard/auto-fill` |
| 3 | توضيح «نشط 30 يوم» في `overview` |

### منتجات / أخرى

| # | المطلوب |
|---|---------|
| 1 | `DELETE /api/products/{id}` — إرجاع `{ success: true }` عند النجاح (الواجهة كانت تعرض خطأ رغم الحذف) |
| 2 | سعر الدولة في تفاصيل المنتج و`GET` أسعار الحكومة |

## خارج نطاق الواجهة الحالي (طلبات مستقبلية)

- فيديو توضيحي للصفحات
- ربط الإعلانات بصفحات التطبيق
- قائمة سوداء للمستخدمين
- إدارة المزادات/المناقصات/البيع المباشر من الأدمن
- تقرير نقل جديد (من محافظة → إلى محافظة) — يحتاج endpoint جديد
- خريطة حرارية GeoJSON للمحافظات في تحليل «خريطة الإنتاج»
